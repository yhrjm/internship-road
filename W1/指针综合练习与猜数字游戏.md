# 指针综合练习与猜数字游戏

## 一、指针综合练习

### 练习1：纯指针遍历数组求最大值
```c
int arr[5] = {3, 7, 1, 9, 4};
int *p = arr;
int max = *p;                    // 初始化为首元素，不是0
for (int i = 1; i < 5; i++) {
    if (*(p + i) > max)          // 全程不用下标 arr[i]
        max = *(p + i);
}
```

**踩坑记录①：max 初始化为 0 的陷阱**
初版写成 `int max = 0`，数组全为负数时（如 {-5,-2,-9}）会错误输出 0。
修正：`max = *p` 从首元素开始比。
**教训：初始化值本身也要经得起边界数据的检验。**

### 练习2：指针比较的原理
`while (p < end)` 合法的原因：同一数组内元素的地址随下标递增，
指针比较本质上比的是地址大小，走到尾后地址循环结束。

### 练习3：二级指针
```c
int a = 10;
int *p = &a;      // p 存 a 的地址
int **pp = &p;    // pp 存 p 的地址

// *pp  = p 的值 = a 的地址
// **pp = a 的值 = 10
```
内存结构：pp → p → a，两层解引用逐层深入。

## 二、猜数字游戏（完整版）

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main() {
    srand(time(NULL));              // 播种：全程序只播一次
    char again = 'y';
    while (again == 'y') {          // 外层循环：再来一局
        int answer = rand() % 100 + 1;
        int guess, count = 0;       // 每局重新计数

        while (1) {                 // 内层循环：单局猜数
            printf("猜一个1-100的数: ");
            scanf("%d", &guess);
            count++;
            if (guess > answer)      printf("大了\n");
            else if (guess < answer) printf("小了\n");
            else {
                printf("对了！用了%d次\n", count);
                break;              // 只跳出内层
            }
        }
        printf("再来一局？(y/n): ");
        scanf(" %c", &again);       // %c 前的空格：吃掉残留回车
    }
    printf("游戏结束\n");
    return 0;
}
```

**踩坑记录②：srand 只能播种一次**
rand() 是伪随机：同种子必出同序列。srand 放进循环会每秒重复播种
同一种子，导致每次"随机数"完全相同。

**踩坑记录③：scanf("%c") 前的空格**
上一局输入留下的回车符会被 %c 直接读走，程序表现为"跳过输入"。
写成 `scanf(" %c", ...)` 让空格吃掉残留空白符。

## 三、结构设计要点

- 外层循环管"再来一局"，内层循环管"单局猜数"
- count = 0 必须在外层循环内（每局清零）
- break 只能跳出一层循环，内外层退出条件分开设计

# 指针综合与猜数字游戏讲义

> C 语言指针进阶专题：数组遍历、二级指针、随机数与循环结构设计

## 第一课：纯指针遍历数组

### 核心等价关系
```
arr[i]   ≡   *(arr + i)   ≡   *(p + i)   （其中 p = arr）
```
`arr[i]` 只是 `*(arr+i)` 的语法糖。

### 两种写法
```c
int arr[5] = {1, 2, 3, 4, 5};
int sum = 0;

// 写法一：下标计数 + 指针取值
int *p = arr;
for (int i = 0; i < 5; i++) {
    sum += *(p + i);
}

// 写法二：指针自己走
int *p = arr;
int *end = arr + 5;          // 尾后地址
while (p < end) {
    sum += *p;
    p++;
}
```

### 练习
- 题A：不用下标，用指针求数组 `{3, 7, 1, 9, 4}` 的最大值
- 题B：`p < end` 这个比较为什么合法？两个指针比的是什么？

## 第二课：二级指针

```c
int a = 5;
int *p = &a;      // p 里装着 a 的地址
int **pp = &p;    // pp 里装着 p 的地址
```
```
pp ──→ p ──→ a

*pp   = p 的值 = a 的地址
**pp  = a 的值 = 5
```
用途：函数里想修改"一个指针指向哪里"时（如链表插入头节点）。

### 练习
- 题C：`int a=10, *p=&a, **pp=&p;` 写出 `*pp`、`**pp` 各是什么
- 题D：手画三者的内存关系图

## 第三课：随机数与猜数字游戏

### 随机数原理（反直觉但关键）
`rand()` 是**伪随机**：同一个种子生成完全相同的序列。
`srand(time(NULL))` 用当前秒数当种子，**全程序只播一次**——
放进循环里会每秒重复播种同一种子，导致每次"随机数"完全相同。

```c
#include <stdlib.h>
#include <time.h>

srand(time(NULL));                 // 只播一次，放程序开头
int answer = rand() % 100 + 1;     // %100压到0~99，+1变1~100
```

### scanf 读字符的坑
上一局输入残留的回车符会被 `%c` 直接读走，程序"跳过"输入。
写法：`scanf(" %c", &again);`——%c 前的空格吃掉残留空白符。

### 猜数字的结构设计
```
┌─ 外层循环（再来一局）──────────┐
│  生成新答案、计数器清零        │
│  ┌─ 内层循环（单局猜数）────┐  │
│  │  输入 → 判断大小 → 计数  │  │
│  │  猜对 break 出内层        │  │
│  └──────────────────────────┘  │
│  问 y/n，n 则退出外层           │
└────────────────────────────────┘
```
要点：`count = 0` 放外层循环内（每局清零）；break 只能跳一层。

### 练习
- 题E：srand 写进循环每次播种，会发生什么？为什么？
- 题F：实现完整猜数字（随机答案/大小提示/计数/y/n 再来一局）

## 答案区

- 题A：
```c
int max = *p;                    // 初始化为首元素，不是0
for (int i = 1; i < 5; i++)
    if (*(p + i) > max) max = *(p + i);
```
注意：`max = 0` 是陷阱——数组全为负数时会错误输出 0（0 根本不在数组里）。

- 题B：同一数组内元素地址随下标递增，指针比较的本质是比较地址大小，p 未到尾后地址则循环继续。

- 题C：`*pp` = p 里存的值 = a 的地址；`**pp` = 10（a 的值）

- 题E：time(NULL) 精确到秒，一秒内多次播种得到相同种子，每次重新洗回序列开头，取到的永远是同一个数。所以全程序只播种一次。

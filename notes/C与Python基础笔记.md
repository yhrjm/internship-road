# 第一部分：C 语言

## 1. 指针

### 一句话本质
指针 = 存地址的变量。变量是房子，指针是写着门牌号的纸条。

### 三个核心操作符
| 操作 | 含义 | 例子 |
|---|---|---|
| `&a` | 取 a 的地址 | `int *p = &a;` |
| `*p` | 顺着地址读写那个变量 | `*p = 99;` 就是改 a |
| `int *p` | 声明：p 是"指向 int 的"指针 | 类型必须匹配 |

### 指针运算
- `p + 1` = 地址后移**一个元素**（int 即 4 字节），不是 +1 个字节
- `*(p+2)`：先动指针再取值 → 第 3 个元素
- `*p + 2`：先取值再加 2 → 首元素的值 + 2
- `p++`：指针移到下一个元素；`(*p)++`：指向的值 +1

### 传值 vs 传址
- C 函数传参是**值传递**：函数拿到的是**副本**，改副本动不了原件
- 想改原件 → 传地址：`swap(&x, &y)`，函数里用 `*a` 改
- 指针参数两种角色：**in 参数**（只读取）和 **out 参数**（往回写结果）

### 二级指针
- `int **pp`：存"指针的地址"的指针。`pp → p → a`，两层门牌号
- `**pp` = a 的值；`*pp` = p 的值（即 a 的地址）
- 用途：函数里要"改一个指针的指向"时用（如链表插入头节点）

### volatile
告诉编译器：这个变量随时可能被外部（硬件/中断）改变，别优化，每次都去内存老实读。嵌入式寄存器操作必备。

### const 与指针（从右往左读）
| 写法 | 锁了什么 |
|---|---|
| `const int *p` | 值锁死：不能通过 p 改值，p 可换指向 |
| `int * const p` | 指向锁死：p 不可换指向，但可改值 |
| `const int * const p` | 全锁死 |

## 2. 结构体

```c
typedef struct {
    char name[20];
    int id;
    float score;
} Student;

Student s = {"张三", 101, 88.5};
s.score = 90;        // 普通变量用 .
Student *ps = &s;
ps->score = 95;      // 指针用 ->（等价于 (*ps).score）
```
结构体内存对齐：成员不是紧挨排列，编译器按对齐规则填充空隙，`sizeof(结构体)` 经常比手算的大。

## 3. 位操作

| 操作 | 代码 | 效果 |
|---|---|---|
| 置第 n 位为 1 | `n \|= (1 << 3);` | 或运算点亮该位 |
| 清第 n 位为 0 | `n &= ~(1 << 3);` | 与上掩码清位 |
| 判断第 n 位 | `if (n & (1 << 3))` | 非零即为 1 |
| 翻转第 n 位 | `n ^= (1 << 3);` | 异或翻转 |

## 4. C 高频易错清单
1. `=` 和 `==` 写反（if 里赋值不报错，逻辑全错）
2. `*p++` 是 `*(p++)` 不是 `(*p)++`——优先级坑
3. 数组越界不报错，悄悄改坏别的变量
4. 指针没初始化就解引用（野指针）
5. 返回局部变量的地址（函数结束内存已回收）

## 6. 四大数据结构

| 类型 | 写法 | 适用场景 | 高频操作 |
|---|---|---|---|
| 列表 list | `[1, 2, 3]` | 有序的一串 | `append` `a[1:4]` `a[::-1]` 推导式 |
| 字典 dict | `{"name": "张三"}` | 键值对、计数、接口返回数据 | `d[k]` `d.get(k, 0)` `d.items()` |
| 元组 tuple | `(1, 2)` | 不可变的固定组合 | 解包 `x, y = (1, 2)` |
| 集合 set | `{1, 2, 3}` | 去重、交并集 | `set(a)` `a & b` |

## 8. Python 高频易错清单
1. 缩进即语法——tab 和空格混用必崩
2. `b = a` 不是复制列表，是同一个列表的两个名字（用 `a.copy()`）
3. `input()` 拿到的永远是字符串，算数前先 `int()`
4. `d[k]` 取不存在的键会崩，用 `d.get(k)`
5. 循环里删列表元素会跳元素（倒序删或新建列表）

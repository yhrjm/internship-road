## 第 0 课：scanf 防御补丁

### 问题现象

猜数字游戏里输入字母 `a`，程序死循环刷屏。机理：

1. `scanf("%d", &guess)` 期望读到整数，但缓冲区里是字母，解析失败，返回 0（返回值 = 成功读到的项数）；
2. 解析失败时 scanf 不消费缓冲区内容——那个字母还留在缓冲区里；
3. `guess` 保持上一次的旧值，循环条件不成立也不退出，下一轮 scanf 又撞上同一个字母，又失败……无限空转。

### 补丁写法

```c
if (scanf("%d", &guess) != 1) {   /* 没读到整数 */
    printf("请输入数字！\n");
    while (getchar() != '\n');    /* 把缓冲区里这行垃圾全部吃掉 */
    continue;                     /* 重新提示，重新输入 */
}
count++;                          /* 只有合法输入才计数 */
```

要点：检查输入函数的返回值，是「防御式编程」的入门动作。测试工程师的核心直觉：用户永远不会按你想的方式输入。

### 三连测（验证补丁有效）

| 输入 | 期望行为 |
|---|---|
| 字母 a | 提示「请输入数字！」，程序继续等输入，不刷屏 |
| 999 | 提示「大了」，程序正常继续 |
| 直接回车 | 程序仍在等待，不崩不刷 |

## 第 1 课：结构体 struct

### 为什么需要结构体

一个 int 存一个数，一个数组存一堆同类型的数。但现实中的数据是「打包」的：一个学生 = 姓名（字符串）+ 学号（int）+ 成绩（float），三种类型捆在一起。结构体就是 C 语言给的「打包盒」。Python 的字典、接口返回的 JSON，本质都是这个思想的延续。

### 语法三板斧

```c
/* ① 声明：设计图纸，不占内存 */
struct Student {
    char name[20];
    int id;
    float score;
};                  /* 注意这个分号，新手最常丢 */

/* ② 定义 + 初始化：照图纸造实物 */
struct Student s1 = {"张三", 101, 88.5};
struct Student s2;  /* 先定义后赋值也行 */

/* ③ 访问：点号取成员 */
s2.id = 102;
printf("%s %.1f\n", s1.name, s1.score);
```

如果手里是结构体指针，用箭头 `->`：

```c
struct Student *p = &s1;
printf("%.1f\n", p->score);   /* 等价于 (*p).score */
```

常见坑：① C 语言里完整类型名是 `struct Student`，struct 关键字不能省（C++ 才可以省）；② 声明末尾的分号丢了，编译器报的错误会指向莫名其妙的位置；③ 结构体整体赋值 `s2 = s1;` 是合法的（全体逐成员拷贝）。

### 结构体数组 + 遍历（完整示例）

```c
#include <stdio.h>

struct Student {
    char name[20];
    int id;
    float score;
};

int main() {
    struct Student cls[3] = {
        {"张三", 101, 88.5},
        {"李四", 102, 92.0},
        {"王五", 103, 79.5}
    };
    int top = 0;                    /* 先假设第 0 个最高 */
    for (int i = 1; i < 3; i++) {
        if (cls[i].score > cls[top].score)
            top = i;                /* 记下标，不记分数 */
    }
    printf("最高分：%s (%.1f)\n", cls[top].name, cls[top].score);
    return 0;
}
```

注意：基准值用真实数据初始化（假设第 0 个最高），而不是拍脑袋写 0。

**练习**：定义 Student 结构体（姓名、学号、成绩），创建 3 个学生，打印成绩最高者的姓名；变种——打印成绩最低者的姓名和学号。

## 第 2 课：位操作

### 先看懂「位」

一个 `unsigned char` 占 8 个二进制位，编号从右往左是第 0 位到第 7 位。例如十进制 5 = 二进制 `00000101`，它的第 0 位和第 2 位是 1。位操作就是直接对某一个位动手——嵌入式和驱动开发的日常，面试高频考点。

### 六个运算符

| 运算符 | 名称 | 规则 | 例子（8 位） |
|---|---|---|---|
| `&` | 按位与 | 都是 1 才是 1 | 0101 & 0011 = 0001 |
| `\|` | 按位或 | 有 1 就是 1 | 0101 \| 0011 = 0111 |
| `^` | 按位异或 | 不同才是 1 | 0101 ^ 0011 = 0110 |
| `~` | 按位取反 | 0 变 1，1 变 0 | ~0101 = 1010 |
| `<<` | 左移 | 整体左移，右边补 0 | 1 << 3 = 00001000 |
| `>>` | 右移 | 整体右移，左边补 0 | 00010000 >> 2 = 00000100 |

### 位操作三件套（背到条件反射）

核心道具是 `1 << k`：造出一个「只有第 k 位是 1，其余全是 0」的数，叫掩码。比如 `1<<3 = 00001000`。

```c
unsigned char n = 0;
n |= (1 << 3);    /* 置位：第 3 位变 1，其他位不动 */
n &= ~(1 << 3);   /* 清位：第 3 位变 0，其他位不动 */
if (n & (1 << 5)) {   /* 判位：第 5 位是 1 吗？ */
    /* 是 1 才会进来（结果非 0 即为真） */
}
n ^= (1 << 2);    /* 翻转：第 2 位 0 变 1、1 变 0 */
```

逐行拆 `n &= ~(1<<3)`：`1<<3` 是 `00001000`；取反后变成 `11110111`——只有第 3 位是 0，其余全是 1；再和 n 相与：凡遇 1 保持原样，第 3 位遇 0 强制清 0。这就是「精确拆除某一位，不伤及无辜」。

**为什么嵌入式寄存器操作全是位操作**：硬件寄存器里每一位（或每几位）控制一个独立功能开关，比如第 3 位开 LED、第 5 位开中断。如果整体赋值 `REG = 0b00001000`，开 LED 的同时把其他位全部清零——别的功能全被误关。所以必须「读-改-写」：用三件套只动目标位，其他位原样保留。

**练习 1**：`unsigned char n = 0;` 写代码：把第 3 位置 1；判断第 5 位是否为 1。

**练习 2**：`n & ~(1<<3)` 这行在干嘛？

## 第 3 课：const 与指针 / volatile

### const 的三种摆法

口诀：const 修饰它左边的东西；左边没东西，就修饰右边。

| 写法 | const 锁住了谁 | 能做什么 / 不能做什么 |
|---|---|---|
| `const int *p` | 锁住 `*p`（指向的值） | 不能通过 p 改值；但 p 可以改指向别处 |
| `int * const p` | 锁住 `p`（指针本身） | p 不能改指向；但可以通过 p 改值 |
| `const int * const p` | 两个都锁 | 既不能改指向，也不能改值 |

```c
int a = 1, b = 2;
const int *p = &a;
/* *p = 10;  编译报错：值被锁 */
p = &b;            /* 合法：指针本身没锁 */

int * const q = &a;
*q = 10;           /* 合法：值没锁 */
/* q = &b;  编译报错：指向被锁 */
```

### volatile 是干嘛的

volatile 告诉编译器「这个变量可能被程序之外的因素随时改变——硬件寄存器、中断服务程序、另一个线程」，禁止优化，每次使用都必须重新从内存读，不许用寄存器里的旧缓存。

经典场景：主循环等硬件标志位 `while (flag == 0) { }`。没有 volatile，编译器一看「循环体里没人改 flag」，就优化成只读一次 → 死循环。加上 `volatile int flag;`，编译器每轮都老老实实重读，中断把 flag 改成 1 时循环才能退出。

**练习**：说出 `const int *p`、`int * const p`、`const int * const p` 三者各限制什么。

## 答案区

**位操作练习 1**：

```c
unsigned char n = 0;
n |= (1 << 3);            /* 第 3 位置 1：n 变成 00001000 */
if (n & (1 << 5)) {       /* 第 5 位是 1 吗 */
    printf("第5位是1\n");
} else {
    printf("第5位是0\n");
}
```

**位操作练习 2**：`n & ~(1<<3)` 把 n 的第 3 位清 0：`1<<3` 只有第 3 位是 1，取反后只有第 3 位是 0、其余全 1，相与时其他位遇 1 不变、第 3 位遇 0 清零。（完整写法应为 `n &= ~(1<<3)`，把结果写回 n。）

**const 练习**：`const int *p`：不能通过 p 改值，但 p 可指向别处；`int * const p`：p 不能改指向，但能改值；`const int * const p`：指向和值都锁死。
